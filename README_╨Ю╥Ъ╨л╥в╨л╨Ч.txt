ENERGYMONITOR — Электр энергиясының шығынын есептеу жүйесі
=========================================================

ЖОБАНЫ АШУ
1. ZIP архивті ашыңыз.
2. EnergyMonitor қалтасындағы index.html файлын Chrome, Edge немесе Firefox браузерімен ашыңыз.
3. Интернет міндетті емес. Егер интернет болса, Manrope қарпі жүктеледі, болмаса жүйелік қаріп қолданылады.

БЕТТЕР
1. Басты бет — айлық тұтыну, төлем, жалпы статистика.
2. Құрылғылар — жаңа құрылғы қосу, іздеу, өзгерту, жою.
3. Калькулятор — қуат, сағат, күн және тариф бойынша есептеу.
4. Статистика — салыстыру графигі, үлестік диаграмма, CSV экспорт.
5. Үнемдеу кеңестері — пайдалы кеңестер және шартты 10% үнем.
6. Баптаулар — тариф, түнгі режим, үлгіні қайтару және тазалау.

ФОРМУЛАЛАР
Энергия (кВт·сағ) = Қуат (Вт) * Сағат/күн * Күн саны / 1000
Төлем (₸) = Энергия (кВт·сағ) * Тариф (₸/кВт·сағ)

НАЗАР АУДАРЫҢЫЗ
Бұл — оқу жобасы және болжамды калькулятор. Нақты есептегішке қосылмайды.
Тариф әдепкіде 25 ₸/кВт·сағ — мысал мән, нақты тариф емес.
Барлық деректер тек осы браузердегі LocalStorage ішінде сақталады.
Backend, сервер немесе деректер базасын орнату қажет емес.

ТЕХНОЛОГИЯЛАР
HTML5, CSS3, Vanilla JavaScript, LocalStorage. Графиктер CSS арқылы салынған.
